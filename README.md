# Simulador de Investimentos em Fundos Imobiliários (FIIs)

Este projeto consiste no desenvolvimento de uma ferramenta prática em Excel para simulação de investimentos em Fundos Imobiliários (FIIs). A planilha foi estruturada para auxiliar investidores a responderem a perguntas essenciais do dia a dia — como quanto investir, por quanto tempo e qual a taxa de rendimento esperada —, automatizando cálculos complexos e oferecendo uma visão clara do potencial de retorno financeiro.

---

## 🚀 Funcionalidades Principais
- **Automação de Cálculos:** Projeções automatizadas para o valor total investido, patrimônio acumulado e dividendos mensais.
- **Simulações Dinâmicas:** Análise de diferentes cenários de tempo, aportes e taxas de rendimento para suporte à tomada de decisão.

---

## 🎯 Objetivos de Aprendizagem
Ao concluir este projeto, você será capaz de:
- Criar ferramentas funcionais de simulação de investimentos em Excel.
- Aplicar conceitos de matemática financeira (cálculo de rendimento mensal e dividendos).
- Documentar processos técnicos de forma clara e estruturada.
- Utilizar o GitHub como plataforma para compartilhamento de documentação técnica.

---

## 🛠️ Detalhes Técnicos e Configurações
O projeto aplica boas práticas de design e engenharia de planilhas para garantir uma experiência de uso profissional:
- **Design e Interface:** Uniformidade visual através de paletas de cores e fontes customizadas, formatação correta de projeções e inserção de banners estáticos (com a propriedade de não redimensionar/mover com as células).
- **Estruturação de Dados:** Utilização de variáveis globais, nomeação de intervalos, tabelas de apoio e mascaramento de dados.
- **Validação e Controle:** Validação de dados por meio de listas suspensas e ocultação estratégica de planilhas.
- **Experiência de Usuário (UX):** Ajustes refinados de visualização, incluindo o gerenciamento da barra de títulos, linhas de grade, barra de fórmulas e modo de tela inteira.

---

## 📂 Como Utilizar
1. Faça o download ou clone este repositório.
2. Abra o arquivo da planilha no Microsoft Excel.
3. Insira os parâmetros desejados nos campos de entrada para visualizar as simulações e projeções financeiras em tempo real.
